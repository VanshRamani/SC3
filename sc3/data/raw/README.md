# Raw input

The pipeline expects the BigSolDB v2.1 tabular release as the raw input
(dataset described in Krasnov et al., *BigSolDB 2.0, dataset of solubility
values for organic compounds in different solvents at various temperatures*,
Scientific Data 12, 1236 (2025)).

Place the raw archive at:
```
data/raw/bigsoldb_v2.1/
```

Source (v2.1, CC-BY-4.0): https://doi.org/10.5281/zenodo.18552681
